This project aims to develop a predictive model to identify students that are likely to be 
classified as highly capable or gifted. By analyzing school districts, academic standards, and 
group characteristics such as race/ethnicity, English language proficiency and socioeconomic 
status. This model will help predict high-achieving students across various schools in 
Washington, US. The predictive model will leverage multivariate analysis and machine 
learning algorithms to discover key contributing factors to a student’s probability of being 
identified as highly capable.
