Summary
This project aims to develop a predictive model to identify students that are likely to be 
classified as highly capable or gifted. By analyzing school districts, academic standards, and 
group characteristics such as race/ethnicity, English language proficiency and socioeconomic 
status. This model will help predict high-achieving students across various schools in 
Washington, US. The predictive model will leverage multivariate analysis and machine 
learning algorithms to discover key contributing factors to a student’s probability of being 
identified as highly capable.

# Predictive Analysis – US Student Performance

## Project Overview
This project focuses on predictive analysis of student performance using real-world educational data. The goal is to analyze key academic, demographic, and behavioral factors that influence student outcomes and to build models that can help predict performance trends.

## Problem Statement
Educational institutions often struggle to identify students at risk early enough to provide timely support. By applying predictive analytics, this project aims to uncover patterns in student data that can help improve academic decision-making and student success strategies.

## Dataset
- US student dataset
- Includes academic performance indicators, demographic attributes, and study-related variables
- Data was cleaned and prepared before analysis

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas & NumPy (data cleaning and manipulation)
- Matplotlib & Seaborn (data visualization)
- Scikit-learn (predictive modeling)

## Methodology
1. Data cleaning and preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Feature selection and transformation  
4. Model development and evaluation  
5. Interpretation of results  

## Key Insights
- Identified key factors influencing student performance
- Observed strong correlations between academic engagement and outcomes
- Predictive models provided useful accuracy in estimating student success trends

## Results
The analysis demonstrates how predictive analytics can be used to support educational planning, early intervention strategies, and data-driven policy decisions.
